# Joongyu

**Automotive CAN reverse engineering · Embedded systems · Full-stack development**

I focus on automotive CAN/CAN FD reverse engineering: inspecting frames, analyzing signals, and understanding how vehicle systems behave. My work connects low-level protocol analysis with embedded firmware, diagnostic tools, and software people can use.

Beyond automotive systems, I build across the frontend, backend, and database layers, with work in computer vision, data pipelines, and workflow automation.
